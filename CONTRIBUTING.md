# Contributing to ai-gateway

Thanks for your interest in improving **ai-gateway**! Contributions — bug reports,
fixes, docs, and ideas — are welcome.

## Getting started
1. Fork and clone the repository.
2. Follow the **Getting started** section in the [README](./README.md) to install
   dependencies and run the project locally.
3. Create a feature branch: `git checkout -b feature/short-description`.

## Making changes
- Keep changes focused and atomic — one logical change per commit/PR.
- Match the existing code style; run the linter/formatter before committing.
- Add or update tests, and make sure the suite passes (see **Testing** in the README).

## Submitting a pull request
1. Push your branch and open a PR against `main`.
2. Describe **what** changed and **why**; link any related issue.
3. Ensure CI is green.
